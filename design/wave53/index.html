Три направления UI

Выбери букву: A, B или C (можно смешать). Пёс — заглушка, на его месте остаётся 3D. Во всех трёх одинаковая раскладка, отличается только стиль.

Убираем в любом из трёх

  • Ряд из 5 кружков (Альбом, Автомат, Дом, Трюки, Игры), кнопки «Двор» сбоку и «Гулять» → один таб-бар внизу
  • Строки текста «Всё хорошо», «Заскучает через 8 ч», «Почеши за ушком? · ещё 59 мин» → кольца/шкалы нужд и просьба значком у пса
  • Кнопка «Шкалы» → шкалы всегда видны, маленькие
  • Плашка «Нажми «Погладить» — +10» → награда прямо на кнопке
  • Задание дня из листа уровня → карточкой наверх главного экрана
  • Полоса «ур. 7» → цифра на аватарке, лист уровня по тапу
  • Двор: без «Ярус «Сад» · уют 29» и «Хватает, бери» — цифры и одна большая кнопка «Забрать»
