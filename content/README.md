# content — тексты питомца

`ru/lines.json` — все слова Шибы: уведомления, виджет, остров, пузыри мысли, лента «Пока тебя не было». Файл кладётся ресурсом в оба таргета (Pet и PetWidgets), код текстов не содержит.

Сейчас: 83 уведомления, 402 реплики виджета, 178 реплик острова, 16 желаний, 60 строк «Пока тебя не было».

## Форма

```
{ "version": 1,
  "notifications": { триггер:   [{"id", "title", "body"}] },
  "widget":        { настроение: [{"id", "text", "tier"?, "frame"?}] },
  "island":        { настроение: [{"id", "text", "frame"?}] },
  "thoughts":      { желание:    {"icon", "text"} },
  "away":          { событие:    [{"id", "text"}] },
  "ui":            { ключ:       [{"id", "text"}] } }
```

- `id` — `<раздел>.<ключ>.<NN>`, уникален во всём файле (`n.` уведомления, `w.` виджет, `i.` остров, `a.` лента). По id строку находят в логах и тестах, поэтому **id не переиспользовать**: текст сильно поменялся — новый id, строка не нужна — удалить, номера не сдвигать.
- `tier` (только виджет, необязателен) — ступень эскалации к ночи, см. ниже. Нет поля — строка годится в любое время.
- `frame` (только `rare` и `rare_sleep`) — ключ редкого кадра: по нему вид найдёт позу или клип пасхалки, а остров — свою строку к тому же кадру. У каждого `frame` виджета есть пара на острове.
- Лишние поля загрузчик игнорирует, `version` растёт только при несовместимой смене формы.

## Как загрузчик выбирает строку

1. **Нет ключа или он пустой** — не падать:
   - виджет и остров → строки `ok` → встроенная «Я тут»;
   - уведомление → не отправлять (или нейтральное «Загляни ко мне»);
   - желание → иконка `pawprint`, текст «…»;
   - лента → карточку пропустить.
2. **Ротация** (07 §2 #12, `app/Shared/LineRotation.swift`): выбор детерминирован от `petId`, ключа и местного времени, чтобы виджет, остров и приложение показывали одно и то же без синхронизации и без истории показов. Строки ключа идут по перестановке от сида, каждый круг она чуть перемешивается внутри блоков, поэтому строка повторяется не раньше чем через 7 дней. Длина хода — от размера пула: самая короткая из 1, 2, 3, 4, 6, 8, 12, 24 ч, при которой пул держит неделю (44 строки `ok` — 4 ч, 30 строк — 6–8 ч). Ходы делят строки без `tier` и с `tier` 1; строки с `tier` 1 и подстановками считаются «может не подойти» и берутся с запасом. Вечером ход строки `tier` 1 занимает строка текущего `tier` (по кругу своих), строка с неподошедшей подстановкой уступает ход предыдущей. Неделю без повторов гарантируем строкам без `tier`; строки эскалации повторяются чаще — их мало. Пул меньше 8 + число строк «может не подойти» неделю не держит: строка меняется раз в сутки, круг — n дней. Уведомления крутятся по дню, лента — по часу, только среди подходящих строк: повтор не раньше чем через min(7, их число) слотов.
3. **Эскалация к ночи** (виджет, как Duo перед полуночью): `tier` 1 — день, 2 — вечер (за 3 ч до отбоя хозяина), 3 — последний час до отбоя. Кандидаты: строки с текущим `tier` плюс строки без `tier`; если таких нет — все строки ключа. Строки `tier` 2–3 выходят только на ходах строк `tier` 1, поэтому в ключе со строками `tier` 2–3 обязательно есть и строки `tier` 1 (тест `testEscalationPoolsHaveTierOneLines`). Ночью питомец спит, срочность ниже не растёт.
4. **Подстановки** `{...}`: если значения нет — брать строку без подстановок (в каждом ключе такая есть).
5. **Редкие кадры** (07 §2 #13): местное время режется на получасы, получасы — на блоки по 20 (10 ч), в каждом блоке ровно один редкий получас, днём (10:00–22:00), если в блоке есть дневные. Итого 1 из 20 точек timeline, дневная пасхалка — не реже раза в 3 дня (на деле — раз в ~сутки). Показывается только без реакции и при `ok`, `sleep`, `nap`: вместо реплики строка из `rare` (во сне — `rare_sleep`), на острове — строка с тем же `frame`. Строка по номеру блока, повтор не раньше чем через 18 блоков (> 7 дней), поэтому в пуле нужно ≥ 18 строк.

## Подстановки

| Метка | Что | Где |
|---|---|---|
| `{friend}` | имя друга в именительном падеже, как в списке друзей | уведомления `gift_arrived`, `friend_poke`; лента `poke`, `friend_pet`, `gift`, `sitter` |
| `{item}` | название вещи или еды в именительном падеже (находка с прогулки — «шишка», `app/Shared/Finds.swift`) | `gift_arrived`, `walk_home`; лента `found_item`, `gift`, `back_home` |
| `{steps}` | число шагов цифрами | лента `steps` |
| `{count}` | число цифрами | лента `poke` |

Тексты написаны так, чтобы падеж и род не ломались: имя друга стоит подлежащим при глаголе настоящего времени («{friend} тыкает меня») или перед двоеточием, числа — после двоеточия («Шагов: {steps}»).

## «Пока тебя не было» — `away`

Лента из 3–6 карточек при открытии после ≥ 2 ч (04 §6.4). Сверху приветствие, в середине события, последняя карточка — главное действие (`cta_*`, кнопку рисует приложение).

| Ключ | Карточка |
|---|---|
| `welcome` | приветствие, не было ≥ 2 ч |
| `welcome_long` | приветствие, не было ≥ 24 ч — тепло, без вины |
| `slept`, `nap` | спал ночью, дремал днём |
| `chased_fly`, `waited_door`, `played_alone`, `zoomies` | чем занимался сам |
| `found_item` | нашёл вещь (`{item}`) |
| `back_home` | вернулся с прогулки с находкой (`{item}`), она уже в альбоме |
| `autofed` | сам поел из автокормушки кухни (улучшение дома), пока хозяина не было |
| `steps` | шаги хозяина за это время (`{steps}`) |
| `poke`, `friend_pet` | друзья тыкали (`{count}`), гладили |
| `gift`, `guest` | пришла посылка, заходил питомец друга |
| `sitter` | жил на передержке |
| `sulked`, `missed` | дулся, скучал |
| `heart_lost` | ушло сердечко — честно и без упрёка |
| `nothing` | ничего не случилось |
| `cta_hungry`, `cta_dirty`, `cta_bored`, `cta_love`, `cta_tired`, `cta_ok` | последняя карточка: самая срочная нужда или «всё хорошо» (прогулка тоже `cta_ok`) |

`welcome`/`welcome_long` и `cta_*` выбирает ядро (`awaySummary()`), события в середине собирает приложение из его списка событий. Если питомец умер, ленты нет.

**Открытка дня — `card_*`** (тот же раздел `away`, `app/Shared/Postcards.swift`): подпись под кадром дня, до 50 знаков. Ключ — тип момента: `card_feed`, `card_treat` (`{item}` — еда), `card_play`, `card_pets` (`{count}` — поглаживаний подряд, есть только у серии от 3), `card_bath`, `card_find`, `card_find_first` (`{item}` — находка), `card_wake` (разбудили от дрёмы), `card_morning`, `card_steps` (`{steps}`), `card_rescue` (вытащили из «Плохо»), `card_first_day`, `card_days` (`{count}` — дней дружбы: 7, 30, 50, 100, 200, 300, 500, 1000), `card_birthday` (`{count}` — лет). Выбор по дню открытки, как у уведомлений.

## Интерфейс — `ui`

Строки экрана, а не слова Шибы: тосты и подписи экономики (`app/Shared/Economy.swift`, `EconText`). Ключи `econ_*` и `capsule_*`, id — `u.<ключ>.01`, в ключе одна строка, ротации нет. Тон нейтральный, без эмодзи.

| Ключи | Что |
|---|---|
| `econ_coin_*`, `econ_ticket_*`, `econ_shard_*` | формы слова для 1 / 2–4 / 5+ (`_one`, `_few`, `_many`) |
| `econ_earned` | тост «+5 монет»: `{count}` число, `{coins}` слово в нужной форме |
| `econ_cap_reached`, `econ_not_enough` (`{count}` — сколько не хватает), `econ_no_tickets` | потолок за день и нехватка |
| `capsule_*` | автомат: кнопка, цены, лимит на день, гарант (`{count}/{total}`), выпало (`{item}`), новинка, дубликат (`{count}` клочков), «тапни» |
| `capsule_rarity_<id>`, `capsule_show_<id>` | редкость и её «выставочное» имя (common, rare, epic, legendary) |

Все ключи, которые читает код, перечислены в `EconText.keys`; тест `testEconTextKeysExist` проверяет, что они есть в файле.

## Тон

- Говорит сам Шиба, от первого лица, в мужском роде. Тёплый, чуть дерзкий, с юмором. Коротко.
- Без канцелярита и без эмодзи: иконки рисует приложение.
- Без давления и вины: никаких «ты плохой хозяин», «он умрёт, если…», сирены. Срочность растёт мимикой и словами постепенно (07 §4). Про критичное — честно и спокойно.
- Про хозяина и друзей — без рода: не «ты пришёл», а «ты здесь».
- Друзьям отвечать не обязательно, тексты так и говорят.
- Новые персонажи (кот, хаски) — позже отдельным файлом или ключами, этот файл про Шибу.
