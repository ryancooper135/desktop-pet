# 04 · Геймдизайн «Питомца»: удержание, сердечки, потребности, экономика, друзья

> Исследование 15.10.2026 · черновик для решений Вадима.
> Все числа живут в `config/economy.json` (сервер отдаёт, клиент кэширует, правка без пересборки). Здесь — почему они такие.
> Числа по уходу и сердечкам проверены симуляцией по часам (скрипт-модель «ленивого пересчёта», см. §3.6). Экономика — расчётом по конфигу (§5.8).

## 0. Главные решения в одну таблицу

| Тема | Решение |
|---|---|
| Смерть | Честная и навсегда. Только при реальном забросе: полный игнор → смерть через **≈ 58–69 ч** (2,4–2,9 суток) |
| Норма | **3–4 захода в день = 0 потерь сердец**. 2 небрежных захода — сердца целы, но питомец грязный и скучает |
| Сердечки | 5 ❤ (6 с будкой L4). Урон только в «бодрствующие» часы хозяина. Ночь сердца **не ест** |
| Предупреждения | 3 уровня: жёлтый «Просит» → оранжевый «Плохо» → красный «Критично» с таймером до смерти |
| Отпуск | Передержка у друга (до 7 дн) или пансион за монеты (80/сут, до 14 дн, шкалы заморожены) |
| После смерти | Страница в альбоме + могилка в «Саду памяти». Дом, монеты, гардероб, уровень хозяина остаются |
| Валюты | 🪙 монеты (всё), 🎟 билетики (капсулы), 🧶 клочки (из дубликатов → Ателье) |
| Доход в день | Активный ≈ **357** брутто / **≈ 310** нетто · Ленивый ≈ **100** / **≈ 65** |
| Долгие цели | Активный: все апгрейды L4 ≈ 6,5 мес, всё-всё ≈ 8 мес + легендарки. Ленивый: все L2 ≈ 3,4 мес |
| Друзья без пушей | Pull-модель: виджет/остров/открытие опрашивают сервер, посылки летят 1–3 ч с известным `deliver_at` → локальное уведомление вовремя |
| Блок Дуо | Встраиваем как есть (WKWebView + `?embed=pet`), результат → монеты, питомец «болеет» за хозяина |

### 1.2 Психология → механика «Питомца»

| Эффект | Как работает | Наша механика |
|---|---|---|
| **Привязанность** | Заботишься → становится «твоим» | Характер подстраивается под хозяина (§4), помнит любимую еду, встречает у двери (bond 9), спит рядом с часами в виджете |
| **Боязнь потери** | Терять больнее, чем получать | Честная смерть + сердечки; стрики с заморозкой; «последний шанс» вместо внезапной смерти |
| **Коллекционирование** | Желание закрыть набор | 4 редкости, капсулы с «pity», альбом трюков/еды/гостей, ачивки |
| **Переменное подкрепление** | Неизвестная награда тянет сильнее известной | Бесплатная рулетка, «Копай!», гости-NPC с сувенирами, подарки «пока тебя не было» |
| **Стрики** | Не хочу обнулить серию | Вход (7-дневный цикл + вехи), стрик дружбы до 5 друзей, заморозка 150 🪙 |
| **Социальное обязательство** | Подвести друга хуже, чем себя | Передержка (друг отвечает за твоего), общий стрик, недельная кооп-цель, SOS-кормёжка |
| **Сюрприз** | Новизна при каждом заходе | Экран «Пока тебя не было», зумиз, случайные просьбы, редкие реплики |
| **Кастомизация** | Вложил = «моё» | Гардероб, мебель, дом с апгрейдами, окрас, имя, рамки |
| **Эффект вложенного прогресса** | Начатое хочется закончить | Старт: уровень хозяина уже 30%, первый квест наполовину, день 1 стрика отмечен, pity капсул с 3/15; питомец «голый и рваный» — первая же ванна даёт видимое преображение |

### 1.3 Выводы для нас

1. **Присутствие > частота.** Виджет и остров дают питомцу «жить» на экране без открытия приложения (урок Finch/Widgetable).
2. **Каждый заход — маленький сюрприз** (Neko Atsume, Animal Crossing), а не только «закрыть шкалы».
3. **Смерть только при реальной брошенности и с честным отсчётом** — иначе получим тамагочи-травму 90-х и удаление приложения.
4. **Социалка — через ответственность и подарки, а не через гонку** (Pikmin, Duolingo Friend Streak).
5. **Никакого шантажа:** уведомления короткие, не ночью, не чаще лимитов; тон — питомец, а не надзиратель.

## 2. Сердечки и честная смерть

### 2.1 Модель

- **Сердец:** 5 (будка L4 → 6). Дробные значения внутри, на экране — половинки.
- **Урон только в «бодрствующие» часы хозяина.** Ночь (выученный график, §4.2) — таймеры урона и «льготы» стоят.
- Урон дают три **состояния беды** (distress), каждое со своей «льготой» перед уроном:

| Беда | Условие | Льгота (бодр. часы) | Скорость урона |
|---|---|---|---|
| Голод | сытость = 0 | 2 ч | −1 ❤ / 5 ч |
| Грязь | чистота < 10 | 8 ч | −1 ❤ / 18 ч |
| Тоска | настроение < 10 **и** ласка < 10 | 8 ч | −1 ❤ / 18 ч |

- Беды складываются (голод + грязь + тоска одновременно ≈ −1 ❤ за 3,4 ч).
- Энергия и движение сердца **не едят** — они влияют через настроение (перекрёстные эффекты §3.3).
- **Последнее сердце** не тает по формуле: при падении до 1 ❤ запускается фиксированный таймер **«последний шанс» = 8 бодрствующих часов**. Смерть не может наступить в первые **3 ч после пробуждения хозяина** — человек должен успеть проснуться и увидеть.
- **Регенерация:** +1 ❤ за 12 бодрствующих часов, если сытость, чистота, настроение и ласка все ≥ 40 (ночью ×0,5). Будка ускоряет (L3 ×1,25, L4 ×1,5).
- **Ускорители:** Витаминка (+0,5 ❤, раз в 24 ч, 150 🪙), Золотая косточка (+0,5 ❤, легендарная еда 200 🪙).

### 2.2 Результаты симуляции

| Сценарий | Итог |
|---|---|
| Полный игнор после последнего захода в 07:30 | смерть через **59 ч** |
| … в 10:00 / 14:00 / 18:00 / 22:00 | 58 / 68,5 / 66 / 66 ч |
| Хронология полного игнора | сытость < 30 ≈ 10 ч (L1) → сытость 0 ≈ 16–23 ч → −1-е ❤ ≈ 25 ч (L2) → 2 ❤ (L3) ≈ 39–57 ч → «последний шанс» ≈ 50–58 ч |
| Игнор, будка L4 (урон ×0,55) | ≈ 84 ч — апгрейд реально страхует |
| 4 захода (08 / 13 / 18 / 22:30) + 6000 шагов | 0 потерь; минимумы: сытость 53, чистота 30, настроение 64, ласка 68 |
| 3 захода (08 / 14 / 21) | 0 потерь; чистота доходит до 25 (мухи) |
| 2 небрежных захода | 0 потерь, но настроение часто 0, чистота ~10 — питомец грустный и вонючий |
| 1 заход в день «до максимума» | ≈ −0,5 ❤/нед — медленное угасание, второй заход его останавливает |
| 1 небрежный заход в день (только еда +45) | смерть ≈ на 6-е сутки — **медленное угасание с честными L1–L3**, о нём надо говорить прямо |

Цель брифа («3–4 захода — всё отлично, умирает только при 2–3 днях реального забвения») выполнена.

### 2.3 Три уровня предупреждения

| Уровень | Цвет | Когда | Уведомления | Что видно |
|---|---|---|---|---|
| **L1 «Просит»** | жёлтый `#E8B931` | любая из сытость/чистота/настроение/ласка < 30 (или прогноз пересечения) | локальное на время прогноза, ≤ 3/день, не ночью | Питомец в виджете показывает просьбу; остров — иконка нужды |
| **L2 «Плохо»** | оранжевый `#E8743B` | активна беда **или** потеряно сердце за последние 12 ч | раз в 4 бодр. ч, ≤ 3/день | Друзья видят «ему плохо» в списке; тусклый виджет |
| **L3 «Критично»** | красный `#D93B3B` | ≤ 2 ❤ | раз в 2 ч, ≤ 6/день, Time Sensitive (если доступно при бесплатной подписи — проверить в `res-ios`) | Обратный отсчёт до смерти (`Text(timerInterval:)`), прогноз «если не придёшь — умрёт в чт ~15:00»; лучшие друзья получают кнопку **SOS-кормёжки** |

Все уведомления **локальные** (заранее расписанные по прогнозу из ленивой модели) — пушей не нужно. Пересчитываются при каждом открытии/таймлайне виджета.

### 2.4 Отпуск и «не могу заходить»

| Вариант | Как | Правила |
|---|---|---|
| **Передержка у друга** (с уровня «Друзья», 7 дн) | Хозяин собирает сумку еды (10 слотов), друг принимает | Питомец живёт у друга: шкалы падают как обычно, но друг ухаживает; сердце не ниже 1; друг +40 🪙/сутки (если ≥ 3 ❤) и двойная дружба; максимум 7 дн, потом перерыв 7 дн; друг обязан заходить раз в 24 ч, иначе питомец «сам приходит домой» и обижается |
| **Пансион** | Бронь ≥ 1 ч заранее, 80 🪙/сут, до 14 дн | Шкалы заморожены (минимум 50), урона нет, XP нет; по возвращении — сцена «соскучился» + короткая обида |
| **Ночная защита** | Автоматически по выученному графику | Шкалы почти стоят, урона нет, уведомлений нет |

### 2.5 Смерть и память

- **Сцена:** питомец засыпает у миски/двери, без шока и крови. Текст честный: «Он ждал тебя 2 дня».
- **Страница альбома:** имя, даты, возраст, фото (последнее + лучшее), любимая еда и игрушка, черты характера, друзья, которые помогали, статистика (сколько гладили, игр, шагов вместе), причина, «последние слова» по характеру.
- **«Сад памяти»** (открывается дворик L3, до этого — просто альбом): могилка, друзья могут оставить цветок.
- **Остаётся:** монеты, билетики, клочки, дом и мебель, гардероб, уровень хозяина, альбом. **Теряется:** питомец, привязанность (bond), черты, возраст, его ачивки, стрики дружбы этого питомца.
- **Траур 12 ч** (можно пропустить), потом выбор нового щенка.
- **Наследник:** если прожил ≥ 30 дней — новый щенок получает одну черту (30% от значения) и медальон предка.
- **Перо ангела** (выкл. по умолчанию, решение Вадима): 1 воскрешение в течение 1 ч, только с вехи 365 дней.

## 3. Потребности и формулы

### 3.1 Шкалы

| Шкала | Старт | День, пт/ч | Ночь, пт/ч | Чем наполнять интересно |
|---|---|---|---|---|
| 🍖 Сытость | 70 | −5 | −0,6 | Еда с характером (§5.5): любимое/ненавистное, «приготовь сам» на кухне L4, кормить с руки (тянуть миску) |
| 🫧 Чистота | 35 | −2,5 | −0,25 | Ванна ~1 ч с таймером в острове: намылить (тереть пальцем), смыть, вытереть — пена, отряхивание брызгами по экрану |
| ⚡ Энергия | 80 | −3,5 | **+12** | Сон (ночь), дрёма днём (< 15 → спит 45 мин, +19/ч), тёплое молоко ×1,3; кровать |
| 🎾 Настроение | 60 | −6 | −0,3 | Мини-игры (+18), игрушки, зумиз, гости |
| 💗 Ласка | 50 | −4 | −0,3 | Гладить (зоны: голова/пузико/за ушком — любимая зона своя у каждого), почесать, обнять двумя пальцами |
| 🐾 Движение | 50 | −3 | −0,2 | **Реальные шаги** хозяина (1 пт = 80 шагов), «Апорт», дворик |
| ✂️ Ухоженность | 5 | ≈ −6/сут | — | Расчёска, салон. Чисто косметика: стадии Рваный → Лохматый → Опрятный → Шикарный |

### 3.2 Ленивый пересчёт `state = f(last_state, dt)`

Хранить: значения шкал, `t_last`, сердца, таймеры бед (льгота/урон), seed. При любом обращении (приложение, виджет, остров, сервер для друзей):

1. Разбить `[t_last, now]` на отрезки по границам: начало/конец ночи, пересечение порогов (20, 25, 10, 0 — меняют множители), запланированные события (конец ванны, конец дрёмы).
2. На каждом отрезке скорости постоянны → значение линейное: `v = clamp(v0 − rate·Δh, 0, 100)`. Момент пересечения порога считается аналитически `Δh = (v0 − p) / rate`.
3. Таймеры бед: копят только бодрствующие часы (`awake_overlap(segment)`).
4. Случайности (зумиз, просьбы, гости) — **детерминированные**: `rand = hash(petId, hourIndex, kind)` → клиент, виджет и сервер получают одно и то же без синхронизации.
5. Обновить `t_last = now`. Это ровно паттерн `_star_tick` из «Моей звёздочки» (`v − rate·hours`, clamp, `t = now`), расширенный отрезками и ночью. Пол `STAR_FLOOR = 15` оттуда **не переносим** — у нас смерть настоящая.

Прогноз «когда пересечёт порог» из той же функции → расписание локальных уведомлений и `Text(timerInterval:)` в виджете.

### 3.3 Как шкалы влияют друг на друга

| Если | То |
|---|---|
| Сытость < 20 | настроение и энергия падают ×1,25 |
| Чистота < 25 | настроение ×1,3, ласка набирается ×0,7, мухи |
| Чистота < 10 | запах, гости обходят стороной |
| Движение < 20 | настроение ×1,2, шанс зумиз ×2, ночной сон ×0,85 |
| Ласка > 70 | настроение падает ×0,85 |
| Энергия < 20 | отказывается от игр, игрушки радуют ×0,5 |

| ⚡ **Зумиз** | бодр. и энергия > 60, база 12%/ч (seed), ×2 при движении < 20; после ванны 60%; после торта | поймать 3 раза (мини-игра), канат, или 10 мин сам; если проигнорил — разбросал вещи (−5 чистоты) | носится по экрану/виджету |
| 😤 **Обижен** | проигнорил просьбу > 3 ч, грубо разбудил, TikTok > 30 мин подряд, вернулся после > 24 ч отсутствия | погладить 3 раза, любимое лакомство, или само через 20–60 мин | отворачивается, в виджете нет кнопок; ласка набирается ×0,5 |
| 🏠 В гостях / 🧳 На передержке / 🏨 В пансионе | действие | время / возврат | дом пустой, записка |
| 🏝 Уснул в острове | Live Activity живёт ~8 ч | открыть приложение → «разбудить» (рестарт активности + опрос сервера) | спящий в острове |
| 🚨 Критично | ≤ 2 ❤ | регенерация до 3 ❤ | красный, таймер |

**Просьбы:** до 6 в день (seed), каждая — конкретная нужда («хочу рыбку», «погуляем?», «почеши за ушком»). Выполнил за 60 мин → +5 🪙 и +5 XP; проигнорил 3 ч → обида.

### 3.5 Связь с привычками (подробно в §4)
Шаги наполняют «Движение», сон по графику даёт бонус, будильник без «отложить» — монетки, TikTok > 30 мин — питомец обижается.

### 3.6 Как проверялось
Почасовая модель на Python с этими скоростями, ночью 23:30–07:30, перекрёстными эффектами, льготами и «последним шансом»; прогоны: полный игнор с 5 стартовых часов, 4/3/2/1 заход в день, будка L4. Найденные и исправленные перекосы: смерть в 07:48 сразу после пробуждения (→ правило «не раньше 3 ч после подъёма»), слишком мягкий урон (смерть только на 70–77 ч → ужесточили голод до 2 ч льготы и 5 ч/❤).

## 4. Характер и память

### 4.1 Оси характера (0–100, сдвиг по поведению хозяина, EMA раз в сутки, α ≈ 0,1 — заметно за 1–2 недели)

| Ось | Тянет влево | Тянет вправо | Как проявляется |
|---|---|---|---|
| Ласковый ↔ Независимый | частые поглаживания | редкие заходы, длинные паузы | ласковый просит ласки чаще, но и радуется сильнее; независимый реже обижается |
| Активный ↔ Ленивый | шаги, апорт, зумиз ловишь | мало шагов, игр | активный — чаще зумиз; ленивый — больше дрёмы |
| Общительный ↔ Застенчивый | гости, передержки, игры с друзьями | одиночество | общительный рад гостям (+настроение), застенчивый прячется первые минуты |
| Обжора ↔ Привереда | кормишь часто, вкусностями | кормишь «по делу», ЗОЖ | привереда отказывается от повторов, обжора просит добавки |
| Озорной ↔ Послушный | торты, игнор зумиз | трюки, вовремя спать | озорной иногда «крадёт» вещь со стола в виджете |

- Питомец засыпает через 15 мин после отбоя хозяина и просыпается через 30 мин после его подъёма (не будит раньше хозяина).

## 6. Друзья без серверных пушей

### 6.1 Принцип: pull + предсказуемая доставка
APNs нет (бесплатная подпись). Значит, сервер **никогда не будит** телефон. Всё строится на:

| Канал опроса | Частота | Что делает |
|---|---|---|
| Открытие приложения | всегда | забирает почтовый ящик, «Пока тебя не было» |
| Таймлайн виджета | ~40–70 обновлений/день (бюджет iOS) | короткий GET `/inbox?since=` → App Group; может перепланировать локальные уведомления (проверить на устройстве) |
| BGAppRefresh | несколько раз в день, не гарантировано | то же |
| Кнопки Live Activity (LiveActivityIntent) | при нажатии | опрос + действие («погладить» из острова) |
| Shortcuts-автоматизации | по событиям (зарядка, будильник, фокус) | заодно опрос |

**Ключевой трюк — известное время доставки.** Подарок/открытка «летит» 1–3 ч (как открытки Pikmin, ~12 ч у них). Сервер сразу пишет `deliver_at`. Как только любой опрос увидел посылку (даже за 2 ч до прибытия), клиент ставит **локальное уведомление на `deliver_at`** и `Text(timerInterval:)` в виджете/острове — уведомление приходит ровно вовремя без пуша. Лимит iOS — 64 запланированных уведомления: держим ≤ 20 своих + резерв.

### 6.2 Механики

| Механика | Как | Без пушей |
|---|---|---|
| Добавить друга | код (6 символов), QR, поиск по нику | — |
| **Тык** | мгновенно, копится пачкой («Макар тыкнул тебя 3 раза») | показывается при следующем опросе |
| **Подарок** | еда/игрушка/одежда, +10% упаковка, летит 1–3 ч | `deliver_at` → локальное уведомление |
| **В гости** | твой питомец идёт к другу на 2 ч (виден у него на экране), возвращается с сувениром | отсчёт в острове, возврат по таймеру |
| **Зайти к питомцу друга** | посмотреть, погладить (+5 🪙, ≤ 3/день); при L2+ — видно «ему плохо» | данные из последнего снапшота друга на сервере (тоже ленивый пересчёт по его шкалам) |
| **Передержка** | §2.4 | друг видит чужого питомца у себя как второго |
| **SOS-кормёжка** (Лучшие друзья) | при L3 у друга: одна экстренная кормёжка в сутки (+40 сытости) | друг узнаёт при своём опросе — шанс не 100%, и это честно |

| Лучшие друзья | 90 | SOS-кормёжка, общее фото в альбоме, гости с ночёвкой |

### 6.4 «Пока тебя не было»
При открытии после ≥ 2 ч — экран-лента: что делал питомец (спал, гонял муху, ждал у двери), кто тыкал, что пришло, что нашли гости, сколько прошли вместе. 3–6 карточек, последняя — главное действие («Он голоден — покормить»). Это главный «сюрприз» каждого захода.

### 6.5 Live Activity как индикатор
- Показывает: ближайшую нужду и таймер до неё, ванну, гостя/посылку в пути, L3-отсчёт.
- Живёт ~8 ч → механика «**уснул в острове**»: питомец засыпает, открой приложение — «разбуди» (рестарт активности + опрос). Превращает ограничение в повод зайти.
- Кнопки (LiveActivityIntent): погладить, дать хрустик из запаса, открыть.

### 7.1 Как встроить Блок Дуо (код не меняем сейчас — план)

Что есть: Cloudflare Worker + Durable Object `Room` на комнату (`/ws?r=<room>`), игроки по `pid` (`^[a-z0-9]{6,40}$`), режимы `b120/b180/b300/classic`, `finalize()` считает победу/ничью, h2h, рекорды и историю (40 матчей); клиент шлёт `fx {n, c, p}` (линии, комбо, perfect). Очки: `40·n·(n+1)·combo`, perfect +500.

План:
1. **WKWebView** на `https://blockduo.spotify-together.workers.dev/?embed=pet&pid=<petPid>&name=<имя>&av=<эмодзи>&r=p<hash(пары друзей)>` — комната = отсортированная пара (≤ 24 символов, `[a-z0-9_-]`, `cleanRoom` уже это режет).
2. **JS-мост** `window.webkit.messageHandlers.pet.postMessage({t:'result'|'fx', …})` — питомец под полем реагирует на `fx`: 2+ линии — прыгает, комбо — лает, perfect — зумиз; проигрыш — утешает.
3. **Начисление — на сервере**, не из клиента: в `finalize()` и `solo` Room-DO отправляет результат в Worker питомца через service binding с общим секретом → монеты по формуле `min(70, 10 + floor(√score / 2,2))` соло, 15 / +20 / +10 дуо, +20 рекорд. Так монеты нельзя накрутить из WebView.
4. Режим `embed=pet` прячет шапку/профиль игры (имя и аватар берутся из питомца).
5. Квесты: «Сыграй в Блок Дуо с другом», «Набери 3000 очков».

## 8. Локальная аналитика

### 8.1 Событие
```json
{ "ts": 1792051200, "dev": "iphone-air", "pet": "p_7f3a", "kind": "feed", "props": { "item": "fish", "food_before": 22 }, "src": "widget" }
```
`src`: `app | widget | island | control | notif | shortcut | pc`.

Хранение: JSONL/SQLite в App Group → пачкой на сервер при открытии (≤ 1 раз в 10 мин) → D1 → еженедельный Cron-отчёт (пн 10:00). Сырые события 90 дней.

### 8.2 Типы событий
`open`, `close`, `widget_tap`, `island_tap`, `notif_open`, `feed`, `pet`, `bath_start/end`, `play`, `minigame_end{game,score,coins}`, `request_shown/done/ignored`, `state_enter{state}`, `heart_change{delta,cause}`, `warning{level}`, `death{cause,age}`, `coins{delta,source|sink}`, `purchase{item,price}`, `capsule{rarity,pity}`, `roulette{reward}`, `streak{day|break|freeze}`, `friend_action{kind}`, `gift_send/receive`, `sitting_start/end`, `habit{kind}`, `sleep_learned{bed,wake}`.

### 8.3 Метрики

| Метрика | Норма | Если хуже |
|---|---|---|
| Заходов в день (медиана) | 3–5 | < 2: усилить «Пока тебя не было», просьбы |
| Доля касаний по поверхностям (app / виджет / остров) | виджет+остров ≥ 40% | низко — виджет неинформативен |
| Время реакции на просьбу (медиана) | < 60 мин | > 2 ч — просьбы неуместны/не видны |
| Потеряно сердец в неделю (медиана) | < 0,5 | > 0,5 → смягчить скорости на 10% |
| Время в L3 | редко | частое — ранние предупреждения не работают |
| Мини-игр в день | 1–3 | > 8 — гринд, ужать монеты |
| Траты / доход 7 дн | 0,7–1,05 | > 1,1 — дефицит; < 0,6 — инфляция |
| Медиана баланса / цена следующей цели | < 2 | > 2 две недели — нужен контент |
| Стрики (вход, дружба) | рост | обрывы после 7-го дня — вехи слабые |
| Капсул в неделю, доля дубликатов | — | дубликаты > 60% — расширить пул |

### 8.4 Еженедельный отчёт (Вадиму в Telegram или на экран настроек)
1. Сводка по каждому игроку: заходы/день, сердца ±, стрик, монеты +/−.
2. Топ источников и стоков монет.
3. «Узкие места»: какая нужда чаще всего падала ниже 25, в какие часы.
4. **Автопредложения** правок конфига по правилам из 8.3 (например, «чистота < 25 у 3 из 4 игроков 40% дня → `clean.day_per_h` 2,5 → 2,2»). Применяются вручную правкой `economy.json`.
