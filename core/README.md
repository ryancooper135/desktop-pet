# core — ядро питомца

Одна и та же логика на двух языках: `ts/` (песочница, сервер, тесты) и `swift/` (приложение и виджет).
Правила и баланс — только в `config/economy.json`, в коде чисел нет.

## Запуск

Нужен Node 24 (умеет запускать .ts без сборки). Всё из корня репо.

| Что | Команда |
|---|---|
| Тесты TS | `node --test "core/ts/test/*.test.ts"` |
| Пересобрать векторы для Swift | `node core/ts/tools/vectors.ts` |
| Таблица баланса | `node core/ts/tools/balance.ts` |
| Бандл для браузера | `node core/ts/tools/bundle-web.ts` → `core/web/petcore.js` (глобальный `PetCore`) |
| Тесты Swift (macOS, CI) | `cd core/swift && swift test` |

CI (`.github/workflows/core.yml`) гоняет TS-тесты, пересобирает векторы, проверяет, что они не поменялись, и запускает `swift test`.

`bundle-web.ts` снимает типы через `node:module` `stripTypeScriptTypes`, убирает `import`/`export` и заворачивает `rules.ts` + `engine.ts` в один IIFE. Код движка руками не переписывается, поэтому песочница считает ровно то же, что тесты и Swift. После правок в `src/` бандл надо пересобрать.

## Как устроено

- **Состояние от времени.** `stepTo(s, R, owner, t)` лениво догоняет состояние шагами по 60 с; `advance` — то же на копии. Разбивка интервала на куски не меняет результат (тест `chunks = whole`).
- **Порядок операций в шаге** (`step` в engine.ts): конец дрёмы и ванны → ночь, бонус лежанки при пробуждении, дрёма при низкой энергии → модификаторы (дом + перекрёстные эффекты) и активные бедствия по шкалам **до** убыли → убыль шкал и энергия → grace и урон сердцам (только в бодрые часы хозяина) → восстановление сердец → последнее сердце и смерть.
- **Ночь.** Хозяин спит в `[bed, wake)`, питомец — в `[bed+15 мин, wake+30 мин)`. Урон копится только в бодрые часы хозяина. Последнее сердце — таймер 8 бодрых часов, смерть не раньше 3 ч после подъёма.
- **Действия.** `act(s, R, owner, action)` → `{ok, reason}`; отказ не меняет состояние. Причины: `dead`, `unknown_item`, `bathing`, `cooldown`, `asleep`, `tired`, `not_napping`.
- **Прогноз.** `forecast(s, R, owner, horizonH)` — события `low`, `level`, `distress`, `heart`, `last_chance`, `death` без ухода; на нём строятся уведомления и timeline виджета.

## Векторы

`core/vectors/*.json` генерирует TS, Swift обязан их повторить с допуском 1e-6:

```
{ name, owner, start: PetState,
  steps: [ {t, do: Action, ok, reason} | {t, expect: PetState, level, moods} ],
  forecast: { from: PetState, horizonH, events: [{t, kind, key, value}] } }
```

Поменял логику → `node core/ts/tools/vectors.ts`, закоммитить векторы вместе с кодом.
