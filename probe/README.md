# Сборка-зонд

Маленькое приложение «Зонд», которое проверяет на твоём iPhone самое рискованное в проекте до того, как писать игру. Питомец тут — эмодзи, красоты нет специально.

## Как получить .ipa

1. Репозиторий на GitHub (его ещё нет — ждёт твоего ответа: приватный или публичный и как назвать).
2. Вкладка Actions → `probe-ipa` → Run workflow. Через 5–10 минут внизу будет архив `PetProbe-ipa` с файлом `PetProbe.ipa`.

## Как поставить

1. На ПК поставить [Sideloadly](https://sideloadly.io) и iTunes (версия с сайта Apple, не из Store).
2. iPhone кабелем к ПК, нажать «Доверять».
3. В Sideloadly: перетащить `PetProbe.ipa`, ввести свой Apple ID **сам** (я пароли не ввожу), Start.
4. На iPhone: Настройки → Основные → VPN и управление устройством → свой Apple ID → Доверять.
5. Настройки → Конфиденциальность → Режим разработчика → включить (телефон перезагрузится).

Бесплатная подпись живёт 7 дней, потом переустановить тем же способом.

## Что проверить (и прислать скрин)

| # | Что | Как | Хорошо, если |
|---|-----|-----|--------------|
| 1 | Общая папка (App Group) | открыть Зонд, раздел 1 | «✅ общая папка есть» |
| 2 | Виджет | добавить виджет «Зонд» на рабочий стол, нажать 🍴 | число еды в приложении растёт, «Виджет видит группу … ok» |
| 3 | Остров | раздел 3 → «Запустить», свернуть приложение, нажать 🍴 в острове | число растёт без открытия приложения |
| 4 | Пункт управления | добавить кнопку «Покормить питомца» | еда растёт, источник control |
| 5 | Шаги | раздел 4 → «Запросить шаги» | число шагов за сегодня |
| 6 | Уведомления | раздел 5 → разрешить → «через 10 сек», свернуть | пришло уведомление |
| 7 | «Команды» | автоматизация «Зарядное подключено» → «Покормить питомца (автоматизация)» | в разделе 6 появилась запись |
| 8 | Отрисовки виджета | через пару часов глянуть «Отрисовок виджета» | видно, как часто iOS сама будит виджет |

Если что-то не работает — скрин раздела 1 (там ID группы и откуда он взят) скажет почти всё.
